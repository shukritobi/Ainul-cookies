# Ainul Cookies Website Preview

A lightweight, mobile-first single-page website for Ainul Cookies, built around the brand’s current pink-and-black identity and new 1 Utama presence.

## Included
- Brand landing page
- Current 1 Utama outlet callout
- Researched menu catalogue and pricing
- Client-side shopping bag
- WhatsApp order handoff
- Instagram, Threads, WhatsApp and Maps links
- Responsive layout with no framework or build step

## Research used
Public-facing sources were checked against the supplied current Instagram / Threads screenshots, including Ainul Cookies’ public menu listings, MMU Alumni’s business directory profile, Tropicana Corporation features about the brand and its founder, IOI Mall Damansara tenant imagery, and 1 Utama / ONECARD’s current outlet listing.

## Notes before production launch
Product availability, final pricing, opening hours, order phone number and outlet details should be reconfirmed by the business. The cart currently hands the order to WhatsApp. A production payment gateway can be connected after merchant onboarding and credentials are available.

This is plain HTML, CSS and JavaScript. Publish the repository root from the `main` branch in GitHub Pages settings.
